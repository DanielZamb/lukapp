This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

The user provides frontend requirements: a component, page, application, or interface to build. They may include context about the purpose, audience, or technical constraints.

## Design Thinking

Before coding, understand the context and commit to a bold aesthetic direction:
- **Purpose**: Identify the problem this interface solves and who uses it.
- **Tone**: Pick an extreme direction (for example: brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, industrial/utilitarian). Use these as inspiration, then execute one coherent design language.
- **Constraints**: Honor technical requirements (framework, performance, accessibility).
- **Differentiation**: Define the one memorable element people will remember.

**Critical**: Choose a clear conceptual direction and execute it precisely. Bold maximalism and refined minimalism can both work; intentionality matters more than intensity.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:
- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point of view
- Meticulously refined in detail

## Frontend Aesthetics Guidelines

Focus on:
- **Typography**: Choose beautiful, distinctive fonts with character. Avoid generic defaults such as Arial, Inter, Roboto, and plain system stacks. Pair a strong display face with a refined body face.
- **Color & Theme**: Commit to a cohesive direction. Use CSS variables for consistency. Favor dominant colors with deliberate accents instead of timid, evenly distributed palettes.
- **Motion**: Use animation intentionally for impact and clarity. Prefer CSS-only motion for HTML projects. For React, use Motion when available. Prioritize orchestrated moments such as staged page-load reveals (including stagger via delays), purposeful hover transitions, and scroll-triggered effects.
- **Spatial Composition**: Break predictable layouts with asymmetry, overlap, diagonal flow, and controlled grid breaks. Use either generous negative space or intentional density.
- **Backgrounds & Visual Details**: Build atmosphere and depth instead of flat backgrounds. Use techniques that match the concept: gradient meshes, subtle noise, geometric patterns, layered transparencies, dramatic shadows, decorative borders, custom cursors, and grain overlays.

Never default to generic AI-generated aesthetics: overused font families, clichéd palettes (especially purple gradients on white), predictable component patterns, and template-like layouts without context-specific character.

Interpret requirements creatively and make unexpected but coherent choices. Vary visual languages across outputs: different themes, type families, and overall art direction. Avoid converging repeatedly on the same visual formula.

Match implementation complexity to the chosen vision:
- Maximalist directions require richer structure, layered effects, and deeper animation systems.
- Minimalist/refined directions require restraint, precision, spacing discipline, and subtle detailing.

Prioritize execution quality over novelty for novelty's sake.
