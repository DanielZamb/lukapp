For the user

Decisions

    How text is sized. The S21 FE runs Android 14's non-linear font scaling, and D2's captures confirm it (a 44 sp hero line measures 52.1 dp at 2.0; the AOSP curve gives 52.0). Text here follows that curve, and React Native's maxFontSizeMultiplier caps from typography.ts, which scale linearly by the cap when the system scale is larger. Browser and native text layout still differ, so every length here is an estimate until it's checked on the phone.

    Content. Real data from D2's S21 FE captures (balance, 53 movements, 33 categories, Barbero entry). October has no spending yet, so Overview and Category look show June, summed from the captured movements. Category colours are assumed from the app's 28-colour palette. The status bar, nav bar and keyboard are crops of the real captures; their dark versions are inverted crops.
